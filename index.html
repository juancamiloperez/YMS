Conectar a Supabase
Configure las credenciales para activar la base de datos en tiempo real
¿Cómo obtener estas credenciales?
1. Vaya a supabase.com → su proyecto → Settings → API
2. Copie la Project URL y la anon/public key
3. Asegúrese de haber ejecutado el SQL de creación de tablas (ver guía técnica)
Modo sin BD: Funciona con datos en memoria. Los datos se pierden al cerrar el navegador y no se sincronizan entre usuarios.

Con Supabase: Datos persistentes, multiusuario simultáneo, historial completo.
